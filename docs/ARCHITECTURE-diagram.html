Per-Agent Flow Visuals

1. Security Analyst (Alerts Triage)

Cron (*/30m, PT, outside quiet hours) │ v Security Analyst agentTurn (isolated) │ ├─(optional) exec → node agents/security-analyst/runner.js --mode collect │ │ │ └─> writes alerts.json → artifacts/cron/security-analyst/<STAMP>/alerts.json │ ├─> Load latest alerts.json │ ├─> For chosen top alerts (3–5): │ ├─ Purple MCP: get_alert, get_alert_notes, get_alert_history │ ├─ Extract IOCs (IP/domain/url/hash/CVE) from full alert context │ └─ TI MCP: enrich_indicator, cve_report as needed │ ├─> Triage & prioritize alerts with reasoning │ ├─> Write artifacts: │ ├─ focused_alerts.json (optional) │ ├─ enrichment.json │ └─ report.md │ └─> Emit chat summary (always, outside quiet hours)

2. Vulnerability Manager (Risk Posture)

Cron (daily 07:00 PT) │ v Vulnerability Manager agentTurn (isolated) │ ├─ exec → node agents/vuln-manager/runner.js --mode collect │ │ │ └─> vulnerabilities.raw.json → artifacts/cron/vuln-manager/<YYYYMMDD>/ │ ├─> Load vulnerabilities.raw.json ├─> Load previous last.json if present │ ├─> Reason about changes: │ ├─ New vs old │ ├─ Severity/status shifts │ └─ KEV / exploited-in-the-wild / EPSS-like indicators │ ├─> Risk-based prioritization: │ ├─ Top N vulns/CVEs by impact │ ├─ Group by software/product/asset │ └─ TI MCP cve_report for key CVEs │ ├─> Write artifacts: │ ├─ prioritized.json │ ├─ changes.json │ ├─ report.md │ └─ update last.json │ └─> Emit chat summary (top risks + remediation suggestions)

3. TI Analyst (Digest & IOC Feed)

Cron (daily 05:00 PT) │ v TI Analyst agentTurn (isolated) │ ├─ TI MCP: enrich_indicator, bulk_enrich, cve_report, etc. │ ├─ Curate threats: │ ├─ Ransomware / infostealers │ ├─ APT / high-impact campaigns │ ├─ High-impact CVEs (KEV/exploited) │ ├─ Rate relevance for this environment │ ├─ Write artifacts: │ ├─ digest.md (human-readable) │ └─ ti_iocs.json (machine-consumable for hunters) │ └─ Emit chat summary + “For other agents” pointers

4. Threat Hunter (Alert-Driven)

Cron (weekly Mon 08:00 PT) │ v Threat Hunter agentTurn (isolated) │ ├─ exec → node agents/threat-hunter/runner.js --mode collect │ │ │ └─> alerts.raw.json → artifacts/cron/threat-hunter/<YYYYMMDD>/ │ ├─> Load alerts.raw.json (24h window + alerts) │ ├─> Derive 2–5 alert-driven hypotheses: │ ├─ lateral movement from host(s) in alerts │ ├─ credential theft follow-up │ └─ C2 / malware activity based on existing alerts │ ├─> For each hypothesis: │ ├─ Purple: get_alert, get_alert_notes, get_alert_history │ ├─ Extract alert-driven IOCs │ ├─ (Optional) TI MCP for deeper understanding of those IOCs │ ├─ purple_ai → generate PowerQueries │ └─ powerquery → execute hunts │ ├─> Interpret results and write: │ ├─ hypotheses.json │ ├─ powerqueries.json │ ├─ results.json / per-query files │ └─ report.md │ └─> Emit chat summary (what was hunted, evidence/no evidence, follow-ups)

5. Proactive Threat Hunter (TI-Driven)

Cron (weekly Mon 08:00 PT) │ v Proactive Threat Hunter agentTurn (isolated) │ ├─> Use TI MCP (+ TI Digest feed) to select high-value IOCs ├─> Design PQ hunts via purple_ai ├─> Execute via powerquery over recent window (~7d) ├─> Interpret results and write TI-hunt artifacts └─> Emit chat summary focused on TI-driven threats

6. SOC Manager (Overview + QA)

Cron (weekly Mon 09:00 PT) │ v SOC Manager agentTurn (isolated) │ ├─> For each agent: │ ├─ Find latest artifacts under artifacts/cron/<agent>/ │ └─ Read report.md + key JSONs │ ├─> Build per-agent summaries (alerts, TI, vuln posture, hunts) │ ├─> QA / fact-check: │ ├─ Compare conclusions vs raw data │ ├─ Cross-check agents (TI vs Vuln, Alerts vs Hunts, etc.) │ └─ Record corrections / reconciled view │ ├─> Write overview.md under artifacts/cron/soc-manager/<YYYYMMDD>/ │ └─> Emit weekly chat summary (executive bullets + key corrections)
